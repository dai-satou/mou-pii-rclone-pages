プライバシーポリシー

最終更新日: 2026年10月21日

「Mou-pii rclone」は、作成者本人が自分のファイルをバックアップするために使う個人用のツールです。

利用するデータ

  • Googleドライブ上で、このツール自身が作成したファイルのみを利用します（スコープ: drive.file）。
  • それ以外のドライブ上のファイル、メール、連絡先などにはアクセスしません。

収集・提供・利用目的

  • データの収集は行いません。
  • 第三者への提供・販売は行いません。
  • 広告には利用しません。

認証情報の保存

認証情報は本人のパソコン内にだけ保存し、外部のサーバーには送信しません。

連絡先

GitHubのプロフィールをご覧ください: github.com/dai-satou

Privacy Policy

Last updated: October 21, 2026

"Mou-pii rclone" is a personal tool used by its author to back up the author's own files.

Data we use

  • Only files on Google Drive that this tool itself created (scope: drive.file).
  • It does not access any other Drive files, email, or contacts.

Collection, sharing and purpose

  • No data is collected.
  • No data is shared with or sold to third parties.
  • No data is used for advertising.

Credentials

Credentials are stored only on the author's own computer and are not sent to any external server.

Contact

Please see the GitHub profile: github.com/dai-satou
